# World Parliament — project guide for Claude (read this first)

## What this is
The world (~8.3 bn people, 2026) is divided into **500 parliament seats of ~16.6 m people each** (≈1.66 crore; accepted band 12.5–20.8 m). Each seat is a union of whole countries / ADM1 / ADM2 units. This repo holds (a) the seat definitions, (b) a Python/Node pipeline that turns them into boundaries, and (c) a static, zoomable web map (`maps/world-500/site/`) where seats are drawn instead of countries.
- **Repo layout (two main folders)**: `maps/` = one folder per map (`maps/world-500/` today; later world-250, india-543 …). A map folder has `map.json` (manifest), `thumbnail.jpg`, `site/` (the static study website — everything needed to render: index.html, app.js, style.css, lib/, `data/{world.topo.json, detail.topo.json, seats.json, game.json}`) and, SEPARATELY, `source/` (everything needed to change the map: `build/` pipeline, `data/`, `output/` master CSV, `GEO/`, `reference/`, `README.md`). `game/` = the HUNG PARLIAMENT game, which uses `maps/` generically (see `maps/README.md`). Root also keeps `.github/`, `.claude/`, `FEATURE REQUIREMENTS.docx`, README.md and this file. Below, **`S` = `maps/world-500/source`** and **`M` = `maps/world-500`**; every path in the pipeline section is relative to `S` unless it starts with `M/`.

## Pipeline (all in `S/build/`; run from project root; `S/README.md` mirrors this section)
1. `01_parse_coverage.py` → `S/build/seats_parsed.json` (recursive parser; must report 0 anomalies).
2. `02_resolve_names.py` → `build/resolved.json`, `unmatched.csv`, `fuzzy_report.csv`. Matches CSV names to geometry units: normalise → alias files `S/data/aliases/*.json` (keys `country`, `adm1`, `adm2`, `approx`, `expand`) → affix/prefix/difflib fuzzy. Options: `--tag=X --iso=AAA,BBB` (scratch run in build/tmp_X). **Goal: unmatched = 0.** China ADM1/ADM2 bypasses CGAZ and uses `build/chn_match.py` + DataV layer (see below).
3. `03_build_geometry.py` (≈5–10 min) → `build/seats.geojson` (Equal Earth projected, y down, scale 200) + `build/geometry_report.txt` (overlaps, ambiguous ADM2, "internal slivers removed"). Unions units per seat, subtracts neighbours from China, removes small internal holes (< 3 units², keeps genuine enclaves).
3b. `03b_clean_geometry.py` (≈15 min, 8 processes) → rewrites `build/seats.geojson` in place (raw copy kept as `build/seats_raw.geojson`; re-runs always start from the raw copy). Morphological closing (buffer +0.08 units, −0.08 ≈ 2.5 km) of every seat, with other seats' land subtracted from the added area. This removes hairline gaps between merged units that otherwise show up as **internal / dangling lines** inside seats (e.g. Indiana slit in Chicago, Siachen seams in Himachal–Ladakh). `--seats 1,2 --out x.geojson` for a test run. Needed after every 03 run. (`build/check_internal_lines.py` = arc-reuse check on the TopoJSON; `build/qa_geometry.py` = noisy heuristic QA — the reliable check is looking at renders.)
3c. `03c_close_seat_gaps.py` (≈10 min) → rewrites `build/seats.geojson` (pre-03c copy kept as `build/seats_pre03c.geojson`; use `--refresh` after every 03b run). Closes narrow (~1–3 km) land gaps BETWEEN neighbouring seats (border mismatches between source datasets) on 0.002-simplified geometry (full-res is far too slow), sharing each gap piece among the neighbours. Needed after every 03b run.
4. `04_simplify.sh` → `M/site/data/world.topo.json` (coarse) and `detail.topo.json` (loaded lazily when zoom > ~4×) via local `build/node_modules/mapshaper`.
5. `S/build/node_modules/.bin/…mapshaper M/site/data/world.topo.json -o S/build/world_simple.geojson format=geojson` (used by step 6 for colouring/adjacency — no longer shown).
6. `05_build_site_data.py` → `M/site/data/seats.json` (pretty-printed; panel data: countries with ISO2 flags, ADM1/ADM2 lists, approx markers, tags).
Standard rebuild (background, ~30 min with 03b + 03c), then wait for `REBUILD_DONE` in `S/build/rebuild.log` (07 regenerates the game package `M/site/data/game.json`; run `npm run gen:maps` in `game/` afterwards if the seat count changed):
```
M=maps/world-500
cp $M/site/data/seats.json $M/source/build/seats.names.backup.json
python -I $M/source/build/01_parse_coverage.py && python -I $M/source/build/02_resolve_names.py
nohup sh -c "python -I $M/source/build/03_build_geometry.py > $M/source/build/rebuild.log 2>&1 && rm -f $M/source/build/seats_raw.geojson && python -I $M/source/build/03b_clean_geometry.py >> $M/source/build/rebuild.log 2>&1 && python -I $M/source/build/03c_close_seat_gaps.py --refresh >> $M/source/build/rebuild.log 2>&1 && sh $M/source/build/04_simplify.sh >> $M/source/build/rebuild.log 2>&1 && (cd $M/source/build && node node_modules/mapshaper/bin/mapshaper ../../site/data/world.topo.json -o world_simple.geojson format=geojson >> rebuild.log 2>&1) && python -I $M/source/build/05_build_site_data.py >> $M/source/build/rebuild.log 2>&1 && python -I $M/source/build/07_game_map.py >> $M/source/build/rebuild.log 2>&1 && echo REBUILD_DONE >> $M/source/build/rebuild.log" &
```
**Never run two rebuilds at once** (they share S/build/ files). After a rebuild: diff names in M/site/data/seats.json vs the backup (only the user's own edits may differ), check `geometry_report.txt` (overlap count is ~8; none involving touched seats), unmatched 0.
A name change alone needs no rebuild. A territory change = edit CSV rows (coverage_T, E, pop_K/pop_millions, pop_flag, changes_vs_old, notes) → pipeline above. Always back up the CSV first (`S/output/*.bakN.csv`, git-ignored).

## Geometry data sources
- `S/GEO/geoBoundariesCGAZ_ADM{0,1,2}` (shp/geojson, gitignored, several GB): main source. dbf names are latin-1 mojibake (read with `latin-1`, see `build/geo_common.py`; many CGAZ names contain `?` for diacritics). Old ADM2 vintage (e.g. India lacks newer districts → `approx` aliases map them to parent districts; Canada ADM2 = 11 Ontario economic regions; Germany-BW approximated at Regierungsbezirk; Italy regions are ADM2; Nepal has duplicate polygon names: 2nd "Saptari"=Siraha, 2nd "Bara"=Parsa).
- `S/data/ne0/ne_10m_admin_0_map_units` (Natural Earth, gitignored): tiny territories absent from CGAZ (Faroe, Cayman, Falklands, Pitcairn, …); a few point-marker circles (`pt:`) for St Helena/Ascension/Tristan and Bonaire/Sint Eustatius/Saba.
- **China**: `S/data/chn_datav/*_full.json` (Alibaba DataV province→prefecture GeoJSON, committed) → `build/06_chn_prefectures.py` → `S/data/chn_prefec.geojson` (prefecture-level units with pinyin keys). CGAZ China ADM2 is county-level (1990s) so it is NOT used. China geometry is clipped by neighbour ADM0+ADM1 (buffer 0.01°) and by the Ladakh claim polygons. DataV coords are GCJ-02 (few-hundred-metre offset, uncorrected).
- **Ladakh/J&K claim**: `S/data/ladakh_claim_extra.geojson` (features "Aksai Chin" = CGAZ unit 112 ∪ small extras, "Shaksgam Valley" = from `S/reference/India_district_map_(de-facto).svg` northern dotted line, georeferenced with `build/india_svg/*.py`, `affine.npy`). Seat 88 = Himachal + Ladakh + Gilgit-Baltistan (+ these). Seat 86 = J&K + Azad Kashmir. Pseudo-countries "Aksai Chin"/"Shaksgam Valley" in coverage_T use alias `geo:data/ladakh_claim_extra.geojson:<name>` (path relative to `S/`). Disputed-area tag text is shown in the panel; no sovereignty statement is implied.
- Alias value syntaxes: `cgaz:ISO[+ISO]`, `ne:NAME`, `pt:lat,lon,radius`, `clip:ISO:UnitName:minx,miny,maxx,maxy`, `geo:file:name`.
- Antarctica = CGAZ ADM0 `ATA`, included in seat 495 (Chile–Antarctica).
